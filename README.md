# 🔗 Link Acadêmico

O **Link Acadêmico** é uma aplicação web desenvolvida com o objetivo de aproximar **estudantes e empresas**, permitindo a criação de perfis e a divulgação de oportunidades profissionais.

O projeto foi desenvolvido utilizando **C# e ASP.NET Core MVC**, com persistência de dados utilizando **Entity Framework Core e SQL Server**.

## 🚀 Funcionalidades

### 👨‍🎓 Estudantes
- Cadastro e autenticação
- Criação e edição de perfil
- Cadastro de experiências
- Visualização de empresas
- Visualização de vagas
- Informações profissionais e links de contato

### 🏢 Empresas
- Cadastro e autenticação
- Criação e edição de perfil
- Visualização de estudantes
- Cadastro e gerenciamento de vagas

### 🔐 Sistema
- Autenticação e gerenciamento de usuários com ASP.NET Core Identity
- Controle de acesso por perfis de usuário
- Persistência de dados com Entity Framework Core
- Banco de dados SQL Server

## 🛠️ Tecnologias utilizadas

- C#
- ASP.NET Core MVC
- Entity Framework Core
- ASP.NET Core Identity
- SQL Server
- HTML
- CSS
- Bootstrap
- Git
- GitHub

## 🗄️ Banco de Dados

O projeto utiliza **SQL Server LocalDB** durante o desenvolvimento.

A estrutura do banco de dados pode ser criada através das migrations do Entity Framework Core incluídas no projeto.

## ▶️ Como executar

### Pré-requisitos

- .NET SDK
- Visual Studio
- SQL Server LocalDB

### Executando o projeto

1. Clone o repositório.
2. Abra a solução `LinkAcademico.sln` no Visual Studio.
3. Restaure as dependências do projeto.
4. Aplique as migrations para criar o banco de dados.
5. Execute a aplicação pelo Visual Studio.
